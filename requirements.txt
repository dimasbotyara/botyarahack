# Минимум — 3.8. Синтаксис всех файлов (gamedev/, run.py, tests/,
# legacy/hacker-app.py) проверен разбором под 3.8, 3.9 и 3.10:
# нет match, walrus, PEP 585 (list[int]) без `from __future__`.
# Рекомендуется 3.11–3.13.
#
# На 3.14+ берите pygame-ce (см. ниже): у классического pygame
# 2.6.1 колёс под 3.14 нет, придётся собирать из исходников.

# ------------------------------------------------------------
#  ЗАВИСИМОСТИ
# ------------------------------------------------------------
# Нужен РОВНО ОДИН пакет. Оба дают одинаковый `import pygame`,
# так что код менять не нужно — ставьте один из двух:
#
# pygame-ce>=2.5.8,<3        ← рекомендуется
#   Активный форк pygame. Колёса под Python 3.10–3.15.
#   Свежее SDL, быстрее выходят исправления.
#
# pygame>=2.6.1,<3           ← классика
#   Оригинальный pygame. Колёса под Python 3.6–3.13.
#   Нужен, если у вас 3.8–3.9: pygame-ce требует 3.10+.
#
# Ставить оба сразу нельзя — они конфликтуют (одно и то же имя
# пакета `pygame`). Ниже версия для классического pygame
# раскомментирована; если берёте pygame-ce — закомментируйте её
# и раскомментируйте строку с pygame-ce.

# pygame-ce>=2.5.8,<3
pygame>=2.6.1,<3
